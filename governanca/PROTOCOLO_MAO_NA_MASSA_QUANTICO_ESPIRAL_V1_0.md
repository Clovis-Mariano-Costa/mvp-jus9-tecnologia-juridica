# Frente MVP — Mão na Massa Quântico em Espiral

**Registro:** 2026-08-07 23:03:00.00000 America/Sao_Paulo  
**Natureza:** experimental, técnico-governada.

## Koan

> Se dois produtos compartilham o mesmo núcleo, em qual linha de código começa a diferença de missão?

## Céu
Princípios aplicáveis: dignidade, legalidade, segurança, autoria preservada, software livre, governança, memória viva, competência e finalidade.

## Inferno
A menor unidade executável deve conseguir responder: `tenant? usuário? perfil? missão? finalidade? competência? fonte? risco? estado?`.

## Regra de construção

`same core != same tenant != same mission != same memory`

A obra deve separar Advocacia Privada e Defensoria Pública em missão, dados, autorização, contexto, memória, fluxo, UX e responsabilidade, ainda que reutilizem componentes.

## Segurança
Toda vulnerabilidade identificada entra imediatamente em tratamento. Enquanto o ecossistema permanece em pré-segredo e dados fictícios, o Presidente Fundador pode autorizar continuidade temporária controlada, mas a vulnerabilidade permanece aberta até correção, reteste e evidência.

## Transição para segredo real
Antes de qualquer uso com segredos reais, clientes, casos, dados sensíveis ou integrações relevantes: rotação de contas/senhas/tokens/chaves; revisão de permissões; isolamento multi-tenant; gestão de segredos; logs minimizados; backup/restore; resposta a incidentes; testes adversariais; registro de evidência.

## Obra
Cada pacote técnico segue:
`princípio -> requisito -> implementação -> teste -> evidência -> antítese -> reteste -> ensino -> retorno ao princípio`.

Nenhum merge ou deploy irreversível é automático nesta frente.
