# MVP Jus 9 Tecnologia Juridica

## Dominio previsto

https://mvp.jus9tecnologia.com.br

## Configuracao Cloudflare Pages

Framework preset: None  
Build command: exit 0  
Build output directory: .  
Root directory: /

## Conteudo

- Pre-cadastro do lider.
- Perfis profissionais.
- Agenda Jus 9 demonstrativa com localStorage, link Google Calendar e download ICS.
- Charlie Echo, IA generativa multimodal, conversacional e juridico-orientada, com governanca humana.
- Configuracoes JSON de perfis e clausulas petreas.

## Fluxo inicial recomendado

1. `index.html` apresenta o MVP e prioriza a Agenda Jus 9.
2. `acessar-mvp.html` e `login.html` explicam o acesso demonstrativo.
3. `app-perfis.html` permite selecionar perfil profissional.
4. `app-painel.html` mostra o mapa de modulos do MVP.
5. `agenda.html` e a primeira experiencia navegavel para demonstracao.

## Limites do prototipo

- Login demonstrativo nao e login real.
- Nao usar dados reais de clientes, processos, documentos, WhatsApp, senhas, tokens ou conteudo de cofre.
- Backend real, autenticacao, banco, permissao, auditoria, Google OAuth e dados sensiveis exigem pacote tecnico proprio.
